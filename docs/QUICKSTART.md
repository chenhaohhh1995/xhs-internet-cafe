# 10分钟发布第一篇探店笔记

欢迎！从这里开始，你很快就能拥有第一组小红书探店内容。

## 你需要准备

- 一个飞书文档，里面放好网吧信息和4张封面底图
- Claude Code 终端（推荐 Git Bash）

## 三步搞定

### 1. 建飞书文档

直接用探店模板：https://my.feishu.cn/wiki/BIwewPsqwi1FlykEORJc9Nisn0d?from=from_copylink

复制模板后，填入网吧信息：店名、位置、配置、特色、荣誉（可选）。表格第一行放入4张封面底图（灯光好的、屏幕大的、沉浸角度的）。

### 2. 告诉 Claude
打开 Claude Code，输入：

```
帮我做一期网吧探店，飞书链接是 https://...
```

### 3. 收文档、发小红书
Claude 自动跑完全流程（大概几分钟），返回一个飞书文档链接。打开文档，在 A/B 两个方向中挑你喜欢的版本，微调文字，发布到小红书。

## 遇到问题？

看 `docs/TROUBLESHOOTING.md`，或直接在 Claude Code 里描述问题。
