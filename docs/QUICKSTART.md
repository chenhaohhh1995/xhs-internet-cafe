# 5 分钟发布第一篇探店笔记

本指南带你从零开始，完成第一次小红书网吧探店内容创作。

---

## 前提条件

- Claude Code 已安装，xhs-internet-cafe Skill 已加载
- 飞书账号（具备云文档读写权限）
- 首次使用时会自动触发环境引导，按提示完成配置即可（约 5 分钟）

---

## 完整流程

```
你填飞书模板 → 发链接给 Claude → AI 自动完成全部创作 → 收飞书文档发布
                    ↳ 提取信息 → 核实参数 → 策划方向
                    → 写4版文案 → 做4张封面 → 打包飞书
```

---

## 第 1 步：复制探店模板

打开飞书探店模板，点击右上角「复制」创建副本：

https://my.feishu.cn/wiki/BIwewPsqwi1FlykEORJc9Nisn0d?from=from_copylink

---

## 第 2 步：填入网吧信息

在你的副本中填入以下内容：

### 基本信息
- **网吧名称**：如"极速电竞馆（南山店）"
- **位置**：城市 + 区域，越具体越好
- **上网价格**：如"大厅 8元/小时，包间 15元/小时"

### 电脑配置
- **显卡**：如"RTX 4070 Super"
- **CPU**：如"i7-14700KF"
- **显示器型号**：这是重点！如"泰坦军团 P27A6S"
- **外设**：键盘、鼠标、耳机品牌型号

### 环境特色
- 装修风格（工业风/赛博朋克/日系简约……）
- 分区布局（大厅区/竞技区/包间/女性专区……）
- 配套设施（水吧/休息区/街机……）

### 荣誉标签（可选）
- 如"大众点评排名第一""深圳电竞必去榜"等

### 封面底图（重要）
在表格第一行放入 **4 张** 封面底图：

| 位置 | 选图建议 |
|------|---------|
| 第 1 张 | 网吧环境全景（灯光好、有纵深感） |
| 第 2 张 | 显示器特写（屏幕亮、画面清晰） |
| 第 3 张 | 网吧门头/招牌 |
| 第 4 张 | 沉浸角度（从顾客视角拍屏幕） |

> 图片越清晰、灯光越好，生成的封面效果越好。

---

## 第 3 步：把飞书链接发给 Claude

在 Claude Code 中输入：

```
帮我做一期网吧探店，飞书链接是 https://my.feishu.cn/wiki/xxxx
```

然后等几分钟。AI 会自动完成以下全部流程：

| 阶段 | 做什么 |
|------|--------|
| 提取信息 | 从飞书文档读取网吧信息 + 下载封面底图 |
| 核实参数 | 搜索核验产品型号、技术参数，多源交叉核对 |
| 策划方向 | 基于网吧特点设计 A/B 两个差异化内容方向 |
| 生成文案 | Gemini 双模型出稿，2 方向 x 2 模型 = 4 版稿子 |
| 生成封面 | 每方向 2 张封面图，共 4 张 |
| 打包交付 | 所有内容整合为一个飞书云文档 |

---

## 第 4 步：查看飞书文档

AI 完成后会返回一个新的飞书文档链接。文档结构如下：

```
# 内容类型A：硬核评测
  ## 封面图 → A1版本 / A2版本
  ## Gemini 3.5 Flash 版本 → 候选标题 / 正文 / 标签
  ## Gemini 3 Flash Preview 版本 → 候选标题 / 正文 / 标签

# 内容类型B：发现宝藏
  ## 封面图 → B1版本 / B2版本
  ## （同上）
```

---

## 第 5 步：选版本、微调、发布

1. 浏览 A/B 两个方向，选一个更符合你账号调性的
2. 对比 2 版文案，挑更好的（或取两者之长组合）
3. 确认封面图是否满意
4. 微调文字（加个人体验细节、调整语气）
5. 发布到小红书

---

## 常见问题

### AI 处理的封面图不满意怎么办？

告诉 Claude 具体哪里不满意（配色、文字形变、排版），AI 会重新生成。

### 想要更多内容方向？

告诉 Claude "再加一个 C 方向"，或指定你想尝试的内容类型（如"探店 vlog 风""测评对比风"）。

### 飞书文档读取失败？

检查飞书文档权限是否设置为"知道链接的人可查看"。

### 更多问题？

详见 `docs/TROUBLESHOOTING.md`，或直接在 Claude Code 中描述你的问题。
