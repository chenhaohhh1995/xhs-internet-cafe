# 操作人员标准作业流程 (SOP)

本文档面向操作人员，说明每期探店内容你负责什么、AI 负责什么，以及交付后怎么做。

---

## 前置准备

你只需要准备好飞书文档，剩下的交给 AI。

### 准备飞书文档

1. 新建一个飞书云文档
2. 插入表格，填入以下信息：

| 字段 | 说明 | 是否必填 |
|------|------|---------|
| 网吧名称 | 准确店名 | 必填 |
| 位置 | 城市 + 详细地址 | 必填 |
| 配置 | 显示器型号、显卡、CPU、外设等 | 必填，越详细越好 |
| 特色 | 装修风格、分区、服务、饮品等 | 推荐 |
| 荣誉 | 好评、排名、认证等 | 可选 |

3. 在表格第一行插入 4 张封面底图（操作：把图片拖入表格第一行的单元格）

**封面底图选择标准：** 灯光效果好、屏幕大面积可见、角度有沉浸感（侧面俯拍或正面平拍均可）。

### 确保代理运行

如果你在中国大陆，确保 Clash Verge 或类似代理已开启，并设置好 `HTTPS_PROXY` 环境变量。

---

## 人机分工一览

| 阶段 | 你（操作人员） | AI（Claude） |
|------|--------------|-------------|
| 准备 | 创建飞书文档，填入网吧信息 + 4张底图 | -- |
| 阶段0 | 把飞书链接发给 Claude | 读取文档，提取文字信息和封面底图 |
| 阶段1.5 | -- | 核验泰坦军团产品参数（自动搜索、交叉验证） |
| 阶段2 | -- | 自动策划 A/B 两个内容方向（不同内容类型 + 钩子手法） |
| 阶段3 | -- | 调用 Gemini API 生成 2方向x2模型 = 4版文案 |
| 阶段4 | -- | 调用即梦 AI 生成 2方向x2张 = 4张封面图 |
| 阶段5 | 收到飞书文档链接 | 将所有产物打包为飞书云文档，返回链接 |
| 阶段6 | 给出反馈（可选） | 根据反馈总结教训，更新规则文档 |

---

## 交付后

### 1. 审阅内容

打开 AI 返回的飞书文档，你会看到：

- **方向A**：2张封面 + 2版正文（分别由 Gemini 3.5 Flash 和 3 Flash Preview 生成）
- **方向B**：同上结构

每个版本含：候选标题、正文、小红书标签。

### 2. 挑选和微调

- 在两个方向中挑你更喜欢的
- 再做一次"这个更好"的挑选，确定最终版本
- 根据你的判断微调标题和正文——不用完全照搬 AI 的措辞

### 3. 发布

你自行在小红书 App 发布即可。**AI 不参与发布环节。**

### 4. 反馈（建议做）

如果某次产出有问题（封面文字变形、植入太硬、方向太像上一期等等），在当前 Claude 会话里直接说。AI 会自动诊断根因、更新规则，让下次更好。

---

## 操作技巧

- **信息越详细，文案越出彩。** 网吧信息表格能填的都填上，不要只给店名和地址。
- **底图决定封面质量。** 4张底图是即梦 AI 生成封面的基础，选图多花两分钟，封面效果好三分。
- **不同网吧对应不同内容类型。** 配置好的走硬核评测，氛围好的走沉浸体验，有故事的发掘叙事——让 AI 帮你判断，不用纠结。
- **同一个会话可以连续做多期。** Claude 会记住最近用过的内容方向和钩子，自动避免重复。
