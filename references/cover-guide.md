# 小红书封面文案生成规范

**品牌方：** 泰坦军团（Titan Army）显示器

---

## 封面结构

竖版 3:4 小红书封面图，由四张实拍照片拼成 **2x2 四宫格**，四宫格之间保留 **2px 白色细线**分割。文字覆盖在图片中间区域。

## 封面三行文案（4种拆法体系）

> 来源：ah-xhs-cover-title-skill 封面三行拆法。三行不是随意写的，有固定拆法规律，4种应对不同内容特征。

封面三行 = 竖版图片从上到下排列的三行大字。每行扮演不同角色，合起来驱动点击。

### 单行字数约束

| 行 | 字数 | 角色 |
|---|---|---|
| 第一行 | 2-8字 | 视觉锚点/场景设定 |
| 第二行 | 4-10字 | 承接展开/制造张力 |
| 第三行 | 3-8字 | 落点结论/反转/行动 |

**硬约束：三行合计 ≤ 25字。** 封面是标题的"视觉翻译"，不能直接复制标题文字。

---

### 拆法一：结论前置型（约40%，最常用）

**结构：** 核心概念 → 展开补充 → 落点结论
**本质：** 先给结论或概念，吸引用户停下来细看。

**网吧探店示例：**
- 5060起步 / 深圳网吧已经 / 卷成这样了
- 这网吧配置 / 比我家里还猛 / 一小时才30
- 三角洲玩家 / 来这家网吧 / 出货率翻倍

**适配钩子：** B顿悟发现、D如何方法、F数字锚点、H热点嫁接

---

### 拆法二：递进悬念型（约25%）

**结构：** 设定场景/身份 → 制造张力/矛盾 → 反转/悬念
**本质：** 用悬念制造好奇心，让目标人群产生"这是在说我"的感觉后点击。

**网吧探店示例：**
- 周末不知道去哪 / 来这家网吧 / 打完不想走
- 每次打瓦都垫底 / 换了这台机器 / 直接MVP
- 以为普通网吧 / 进门那一刻 / 我愣住了

**适配钩子：** E身份圈定、G情绪钩子

---

### 拆法三：祈使直给型（约20%）

**结构：** 祈使动词 → 具体行为 → 行为对象/后果
**本质：** 直接下指令，用户被"指挥"后产生行动冲动。

**网吧探店示例：**
- 强烈建议 / 不出货的朋友 / 带根猫条来XX
- 听劝 / 打瓦的兄弟们 / 来这家试试
- 说真的 / 深圳找网吧的 / 直接来这家

**适配钩子：** A建议祈使

---

### 拆法四：对比撕裂型（约15%）

**结构：** A面常识 → 转折词 → B面真相
**本质：** 用"常识 vs 真相"的撕裂感制造冲击，打破刻板印象后驱动点击。

**网吧探店示例：**
- 以为网吧都一样 / 直到来了这家 / 我错了
- 都说网吧又贵又吵 / 这家直接 / 颠覆认知
- 电竞馆 ≠ 贵 / 这家5060起步 / 30块畅玩

**适配钩子：** C反常识对比

---

### 拆法选择决策表

> 根据阶段3产出的正文内容特征，自动匹配最适合的拆法。

| 内容特征 | 优先拆法 |
|---|---|
| 有具体数字/配置/价格（5060、30块、320Hz） | 结论前置型 |
| 有"我发现/注意到/瞥见"等个人洞察 | 结论前置型 |
| 有反常识观点（网吧还能这样？/这配置这价格？） | 对比撕裂型 |
| 有明确目标人群（打瓦人/三角洲玩家/学生党） | 递进悬念型 |
| 有情绪痛点（不出货/上不去分/不知道去哪） | 递进悬念型 |
| 有"建议/听劝/说真的"等祈使语气 | 祈使直给型 |
| 借势热点（游戏版本更新/赛事/新店开业） | 结论前置型 |

### 提炼规则

从阶段3产出的正文中提取核心卖点，按匹配的拆法生成三行：

1. **先做路由决策：** 扫描正文内容特征 → 对照决策表 → 锁定拆法（1-2种）
2. **再填充三行：** 按选定拆法的结构模板，从正文中提取对应素材填入
3. **最后自检：** 三行合计≤25字、每行字数在约束范围内、封面不复制标题

**约束：**
- 三行合起来读是一个完整的意思，但拆开各行也能独立吸引对应人群
- 第三行必须包含网吧差异化锚点（从正文中提取最亮眼的一个点）
- 不出现"泰坦军团"品牌名——封面是吸引点击的，不是植入位
- Emoji不使用——封面文字保持干净，视觉冲击靠排版
- **封面是标题的"视觉翻译"，不是直接复制**——同样的意思，用更短、更视觉化的方式表达

### 封面短标题（缩略图备选）

> 来源：social-creator-toolkit 封面方法论。

除三行大字外，额外提炼一个 **≤5字** 的封面短标题（英文单词算1字），用于缩略图/小图场景下快速识别。

- **提炼逻辑：** 从正文最强钩子中压缩到5字以内，去掉所有修饰，只留核心
- **示例：** "5060起步""能撸猫的网吧""出货玄学""打到不想走"
- **用途：** 作为三行文案的备选方案，当四宫格文字区域被压缩时可切换为短标题模式

## 视觉参数

| 参数 | 值 |
|---|---|
| 比例 | 3:4 竖版 |
| 分辨率 | 2K 高清 |
| 布局 | 2x2 四宫格实拍照片 |
| 分割线 | 2px 白色 (#FFFFFF)，四宫格之间 |
| 文字位置 | 水平垂直居中，固定不变 |
| 整体调性 | 电竞暗调，小红书探店风格 |

### 文字样式

> 配色从 `jimeng-prompt-template.md` 八套方案中随机选取。**每次生成独立随机，同一网吧的两组封面不重复。** 只随机配色，排布固定居中，装饰固定下划线+外发光。

| 行 | 颜色 | 字号 | 字重 | 特效 |
|---|---|---|---|---|
| 第一行 | 8色随机（亮橘/亮青/正红/电光紫/荧光绿/亮蓝/深橙红/蓝灰） | 中号 | 常规 | 字间距加宽 |
| 第二行 | 白(#FFFFFF) 或 金(#FFD700)（方案决定） | 最大号 | 粗体 | 4-5px 黑色描边 + 外发光 |
| 第三行 | 明黄/亮粉/纯白/浅蓝/琥珀/浅灰（方案决定） | 大号 | 粗体 | 下方 2px 同色装饰短线 |

**八套配色各有适用场景，速选指南见 `jimeng-prompt-template.md`。**

### 字体选择

- 优先使用无衬线黑体（思源黑体/阿里巴巴普惠体风格）
- 粗体有力，适合缩略图远距离阅读
- 三行文字水平居中对齐，字间距均匀

## 文字渲染强制规则

> 以下规则写入即梦提示词，作为负面约束：

- 所有中文文字作为独立文字图层渲染，不参与图片变形/拉伸/液化
- 文字禁止倾斜、旋转、透视变换、弯曲、艺术化扭曲
- 每行文字保持水平基线对齐，字间距均匀，不做任何形变
- 文字笔画完整输出，禁止缺笔、漏字、残字、半字
- 描边效果仅作用于文字轮廓外侧，不侵蚀文字本体
- 如果模型无法保证文字准确，宁可留空黑底不做文字，也不要输出乱码

---

## 每次生成要求

1. **路由决策先行：** 扫描阶段3正文 → 识别内容特征 → 从4种拆法中锁定最适配的 2 种
2. **每种拆法生成 1 组**封面三行文案（共 2 组候选），每组配对应封面短标题 ≤5字
3. **配色随机化：** 两组封面各自独立从 `jimeng-prompt-template.md` 八套配色方案中随机抽取。两组不能抽中同一套。排布固定居中，装饰固定下划线+外发光。
4. 输出时标注每组使用的拆法名称 + 匹配的钩子类型 + 抽中的配色方案，可追溯
