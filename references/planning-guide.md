## 标题公式

### 7大心理触发公式（底层逻辑）

> 来源：social-creator-toolkit 爆款标题方法论。以下7种心理机制是标题抓人的底层逻辑，与下方的5种结构模式叠加使用。

| 公式 | 核心逻辑 | 网吧探店应用示例 |
|------|----------|-----------------|
| **画饼型** | 承诺快速达到理想结果 | "来这网吧打瓦，胜率直接翻倍" |
| **损失厌恶型** | 不看会亏/错过损失 | "深圳这网吧没来过真的亏了" |
| **数字型** | 数字比文字更抓眼球 | "5060起步，一小时才30块" |
| **反认知型** | 颠覆常识引发好奇 | "这！是网吧？" |
| **提问型** | 引发思考不给答案 | "深圳网吧已经卷成这样了吗" |
| **参照物型** | 借熟悉事物做对比 | "比我家4090还流畅的网吧配置" |
| **圈定人群型** | 精准定位目标受众 | "打瓦人必去的网吧" |

**4大引爆词：** 好奇 + 悬念 + 独特观点 + 颠覆认知。每个标题至少命中其中一项。

### 10个小红书高转化句式

> 创作标题时，优先从以下句式中选用。

1. `"[引语]"：[犀利观点]`
2. `[亮点前置] + [设置悬念]`
3. `[数字] + [承诺]`
4. `颠覆[刻板印象]`
5. `[人群]必看`
6. `这个[产品/方法] + [结果]`
7. `别再[错误做法]了`
8. `[数字]个[类别]，[价值]`
9. `后悔没早点[动作]`
10. `[意外发现]？`

### 5种爆款结构模式

**硬约束：20字以内。** Emoji可选不强求。每次创作至少生成 3 个候选标题，优先从不同模式中选取。以下模式按流量潜力排序：

**1. 认知反差型** — 制造"和预期不一样"的冲击
公式：反差词 + 具体细节
- "和时代脱节了，网吧都成这样了？"
- "这！是网吧？"
- "深圳的网咖已经是 next level 了！"
钩子词：成这样了、这是XX？、next level、颠覆认知

**2. 情绪共鸣型** — 瞄准"疲惫打工人"群体，把网吧包装成解压方案
公式：情绪词 + 场景暗示
- "当你累了 1 天"
- "最近压力山大"
钩子词：累了、压力大、犒劳自己

**3. 地域+形容词型** — 用一线/新一线城市制造标杆效应
公式：[城市] + [网吧/网咖] + [形容词/感叹]
- "上海网吧已经这么顶尖了嘛"
- "南宁网咖这么卷吗"
钩子词：这么卷、太卷了、杀疯了、天花板

**4. 新店打卡型** — 制造"必须去看看"的紧迫感
公式：[emoji] + [品牌/商圈] + [新开] + [亮点]
- "🎮 万达新开鲨鱼电竞也太卷了 🔥"
- "新开的电竞馆很哇塞！来了来了！！！"

**5. 实用攻略型** — 降低门槛，让没去过的人也敢点进来
公式：怎么做 + 具体场景
- "第一次去网吧的详细流程"
- "电竞网吧平面布局"
要点：收藏率极高，适合做成系列

**通用钩子词库：** 太卷了、杀疯了、天花板、颠覆认知、居然、next level、这么、也太、很哇塞

## 8种钩子手法（内容切入维度）

> 来源：ah-xhs-cover-title-skill 钩子手法体系。与上方标题公式叠加使用——钩子决定"用什么角度切入"，结构模式决定"用什么句式包装"。

| 代号 | 手法 | 句式特征 | 网吧探店应用示例 |
|---|---|---|---|
| A | 建议祈使 | "建议/听劝/千万不要/尽早…" | "听劝，打瓦人直接来这家" |
| B | 顿悟发现 | "我发现/突然发现/注意到…" | "打完瞥了一眼屏幕背面，我发现…" |
| C | 反常识对比 | "X其实是Y""看似X实则Y" | "这配置这价格？深圳网吧卷疯了" |
| D | 如何方法 | "如何/怎么/N步/N个方法…" | "第一次去网吧的详细流程" |
| E | 身份圈定 | "打瓦人/三角洲玩家/学生党…" | "三角洲玩家必去的网吧" |
| F | 数字锚点 | "5060/30块/320Hz…" | "5060起步，一小时30块" |
| G | 情绪钩子 | "不出货/上不去分/不知道去哪…" | "每次不出货都想换网吧" |
| H | 热点嫁接 | 借势版本更新/赛事/新店开业 | "瓦新赛季，这家网吧直接满座" |

### 钩子匹配规则

- 每篇内容从 8 种钩子中选 **1 种主钩子 + 1 种副钩子**
- 主钩子决定标题和封面三行的核心切入角度，副钩子用于正文不同段落换角度展开
- 选择依据：正文中最突出的内容特征是什么类型的句子（数字？反常识？情绪？身份？），而非话题方向
- 参考最近 3 篇用过的钩子，避免短期内重复使用同一钩子

### 钩子 → 封面拆法映射

> 封面三行拆法详见 `cover-guide.md`。

| 钩子 | 适配封面拆法 |
|---|---|
| A建议祈使 | 祈使直给型 |
| B顿悟发现 | 结论前置型 |
| C反常识对比 | 对比撕裂型 |
| D如何方法 | 结论前置型 / 递进悬念型 |
| E身份圈定 | 递进悬念型 |
| F数字锚点 | 结论前置型 |
| G情绪钩子 | 递进悬念型 |
| H热点嫁接 | 结论前置型 |

## 路由决策流程（创作前快速定位）

> 拿到网吧信息后，在阶段2（策划双方向）中，先跑一遍路由决策，让切入点和钩子选择有据可依。

```
第一层：识别内容特征
  扫描网吧信息 → 最突出的特征是什么？
  ├─ 配置数字突出 → 主钩子 F数字锚点
  ├─ 有反常识反差 → 主钩子 C反常识对比
  ├─ 有明确目标人群 → 主钩子 E身份圈定
  ├─ 有情绪痛点/爽点 → 主钩子 G情绪钩子
  ├─ 攻略/教程属性强 → 主钩子 D如何方法
  ├─ 个人发现/体验 → 主钩子 B顿悟发现
  ├─ 强建议/推荐语气 → 主钩子 A建议祈使
  └─ 借势热点事件 → 主钩子 H热点嫁接
       ↓
第二层：匹配封面拆法
  根据钩子 → 自动锁定封面拆法（见映射表）
       ↓
第三层：选择标题结构模式
  从5种爆款结构模式中选1种，叠加使用
```

选用哪一类，取决于网吧的实际情况：

| 类型 | 适用 | 核心逻辑 |
|---|---|---|
| 硬核测评型 | 配置特别强 | 位置→配置→价格→环境→服务→总评 |
| 发现宝藏型 | 新店/价格优势 | emoji+配置堆料+CTA结尾 |
| 沉浸叙事型 | 有特色项目 | 个人经历切入→具体瞬间→展开体验 |
| 产品种草型 | 外设/显示器好 | 网吧体验好→想买同款设备 |

## 节奏模式

每次创作从以下模式中选用一种，让不同篇读起来节奏不同：

| 模式 | 结构 | 适合 |
|---|---|---|
| A：直给型 | 钩子暴击 → 配置→环境→体验 → 收尾 | 配置特别强，硬核向 |
| B：叙事型 | 到店场景切入 → 展开体验 → 发现亮点 → 回扣 | 有差异化特色 |
| C：反差型 | 预期 vs 实际 → 反转点 → 验证细节 → 结论 | 门头普通但内有乾坤 |
| D：种草型 | 痛点/需求 → 发现解决方案 → 体验验证 → 想拥有 | 外设/显示器突出 |
| E：清单型 | 一句话总评 → ✅分点罗列 → 最推荐 → 收尾 | 信息量大，适合扫读 |

**选模式原则：** 参考最近3篇用过的模式，避开重复。连续两篇不用同一种。

## 小红书爆款要素（每篇必查）

**创作优先级：标题 = 头图 > 标签 > 正文。** 前两者决定是否点进来，正文简简单单说清楚就行。

- **首句即钩子：** 前15字决定用户是否点进来，不说废话，直接抛最有冲击力的信息
- **节奏快：** 句与句之间跳跃感强，不写过渡句，读完一行想读下一行
- **有"收藏点"：** 至少一处让人想收藏的信息（价格清单/配置表/地址/避坑提示）
- **结尾引导互动：** 用具体行为+画面感收尾，让人想接话。如"我又想去撸猫了""记得带猫条"，不说"下次还来""点赞收藏关注"
- **品牌露出要软：** 全篇仅1处提及"泰坦军团"品牌名，且必须出现在游戏体验的自然感受之后，让读者觉得是"作者自己发现的"，不是品牌硬塞的。其余位置通过屏幕观感侧面铺垫（画面细腻、暗部清楚、拖影少等），不重复点名
- **活人感贯穿全文：** 用"挺/比较/也/基本/有点东西"等口语填充词；加入游戏圈层黑话（出大红、撤离率、打瓦）；避免戏剧化形容词堆砌
- **本地SEO：** 标题和正文带地域关键词（南山、蛇口等），方便同城用户搜索发现

## 品牌植入

泰坦军团显示器的植入遵循"自然出现，不硬推"原则。**植入必须软到看不出来是广告**，太硬的植入会被判违规限流。

**铺垫比露出更重要。** 90%的篇幅在写网吧体验和游戏感受，品牌名只在最自然的时刻出现1次。先说画面多爽、操作多跟手，让读者自己觉得"这屏幕不错"，再在某个不经意的瞬间带一句品牌名，然后立刻收住回到体验。品牌名不是正文的目的地，是路过时顺便提了一嘴。

- 不说"推荐""值得买""强烈安利"等推销词
- 不出现显示器型号和面板类型（Mini-LED/IPS/VA 等），素人嘴里不说面板名词。高刷、分辨率等直观规格可以自然提及，但不每篇都写
- 品牌名的1次出现必须像"偶然发现"——打完游戏瞥了一眼屏幕背面、网管随口说了一句、旁边人问了一嘴
- 品牌名出现后立刻收住，不展开夸、不对比、不引导购买
- 全文仅1处出现"泰坦军团"四个字，其余位置通过屏幕观感侧面铺垫

| 方式 | 说明 | 示例 |
|---|---|---|
| 体验铺垫 | 全文主体：写游戏时的屏幕感受，不出现品牌名 | "暗部细节真清楚，对面蹲烟里我一眼就看见了" |
| 唯一提及 | 全文仅1处，必须是"发现感"口吻 | "打完瞥了眼屏幕背面，泰坦军团的，难怪这么清楚" |

**植入规则：** 品牌名仅出现1次，必须是"发现感"口吻（瞥见/听说/注意到），不可是"推荐感"口吻（配置清单式罗列/对比夸赞/引导购买）。唯一提及后立刻切换话题，不在此停留展开。

## 封面图特征

创作配图文案和指导拍摄时参考以下规律：

- **色调：** 高饱和、暖色调为主，灯光效果突出的电竞环境最有视觉冲击力
- **构图：** 展示沉浸式体验元素——大屏画面、RGB 灯效、舒适座椅
- **人物：** 有人物使用场景比纯空镜更有代入感；背影/侧脸拍摄即可，不露脸不影响沉浸感
- **信息标注：** 封面图上标注地点的文字，点击率明显更高
- **首图即广告位：** 首图决定笔记的点击率，优先选灯光最炫、屏幕最大、视角最有沉浸感的那张
- **封面短标题：** 封面大字提取正文最强钩子，**≤5字**（英文单词算1字），简洁有力一眼看懂主题

## 小红书发布策略

### 核心算法指标

> 小红书排序算法的核心权重：**收藏 + 分享 > 点赞 > 评论**。内容设计围绕"让人想收藏"展开。

**对创作的影响：**
- 正文必须有可收藏的硬核信息（配置清单/价格/地址/避坑点）
- 结尾互动引导收藏分享而非单纯求赞
- 标题给好奇心，正文给收藏价值，两者缺一不可

### 推荐发布时间

| 时段 | 窗口 | 说明 |
|------|------|------|
| 晚高峰 | 19:00-22:00 | 首选，用户活跃度最高 |
| 午休 | 12:00-14:00 | 备选，碎片化阅读高峰 |

> 同一网吧探店内容不连续发布，两篇之间至少间隔 1-2 天，避免流量清算。
