# 即梦封面生图提示词模板

**模型：** 即梦 5.0
**模式：** 图生图（以四张实拍照片为底图）
**比例：** 3:4
**画质：** 高清 2K

---

## 随机化机制

**每次生成封面时，从 8 套配色方案中随机抽取一套。** 同一网吧的两组封面各自独立随机，不能抽中同一套。

只随机配色，排布固定居中，装饰固定（下划线 + 外发光）。

## 提示词模板

> **结构：固定开头 + 随机文字参数 + 固定文字渲染规则 + 负面提示词。** 首尾固定不变，中间文字的颜色、字号、描边参数每张封面独立随机。

### 正向提示词（组装模板）

```
[固定开头]
一张竖版 3:4 小红书封面图，由四张实拍照片拼成 2x2 四宫格。
四宫格之间保留 2px 白色细线分割。
文字，放在图片中间区域，文字区域从上到下排列三行大字：

[随机文字参数 — 每张封面独立随机]
- 第一行"{line1}"，{第一行随机颜色}，{第一行随机字号}，字间距加宽
- 第二行"{line2}"，{第二行随机颜色}，{第二行随机字号}粗体，{第二行随机描边+发光}
- 第三行"{line3}"，{第三行随机颜色}，{第三行随机字号}粗体，下方 2px 同色装饰短线

整体调性：电竞暗调，小红书探店风格，文字醒目适合缩略图阅读。

[固定文字渲染规则]
所有中文文字必须作为独立文字图层渲染，不参与图片变形/拉伸/液化
文字禁止倾斜、旋转、透视变换、弯曲、艺术化扭曲
每行文字保持水平基线对齐，字间距均匀，不做任何形变
文字笔画完整输出，禁止缺笔、漏字、残字、半字
描边效果仅作用于文字轮廓外侧，不侵蚀文字本体
如果模型无法保证文字准确，宁可留空黑底不做文字，也不要输出乱码
```

### 字号随机池

每张封面生成时，三行字号各自独立从以下池中随机选取：

| 行 | 可选字号 | 说明 |
|---|---|---|
| 第一行 | 中号 / 偏大号 | 随机二选一 |
| 第二行 | 最大号 / 超大号 | 随机二选一 |
| 第三行 | 大号 / 偏大号 | 随机二选一 |

> 字号解释：中号 ≈ 画面宽度的 1/8，偏大号 ≈ 1/6，大号 ≈ 1/5，最大号 ≈ 1/4，超大号 ≈ 1/3。每次随机不重复上一次组合。

## 图生图输入

**底图来源：** 用户提供的四张实拍照片（门头/前台/环境/设备特写等）

**选图原则：**
1. 优先选灯光炫、屏幕大、视角有沉浸感的照片
2. 四张图色调尽量统一（暖色电竞灯光为主）
3. 避免四张图内容重复（门头+环境+设备+特色各一张）
4. 有人物的图优先于纯空镜

**输入方式：** 将四张图的本地路径或 URL 作为即梦图生图的 reference images 传入。

## 即梦 CLI 调用参考

**CLI 工具：** dreamina（即梦官方 CLI，安装：`curl -s https://jimeng.jianying.com/cli | bash`）

**支持的模型版本：** 4.0 / 4.1 / 4.5 / 4.6 / 5.0
**支持的比例：** 21:9 / 16:9 / 3:2 / 4:3 / 1:1 / 3:4 / 2:3 / 9:16
**分辨率：** 2k / 4k（1k 不支持图生图）

```bash
# macOS/Linux/Windows Git Bash 均兼容 $HOME/bin
export PATH="$HOME/bin:$PATH"

dreamina image2image \
  --images "img1.jpg,img2.jpg,img3.jpg,img4.jpg" \
  --prompt "<正向提示词>" \
  --ratio 3:4 \
  --resolution_type 2k \
  --model_version 5.0 \
  --poll 120
```

**参数说明：**

| 参数 | 说明 |
|------|------|
| `--images` | 本地图片路径，逗号分隔，最多 10 张 |
| `--prompt` | 正向提示词（dreamina 无独立 --negative-prompt，负面约束写入 prompt 末尾） |
| `--ratio` | 3:4（小红书竖版封面） |
| `--resolution_type` | 2k（高清） |
| `--model_version` | 5.0（最新模型） |
| `--poll` | 提交后轮询等待秒数，0=不等待（异步任务需后续 `query_result`） |

**登录：** 首次使用需 `dreamina login` 完成 OAuth 设备授权。后续复用登录态。
**查余额：** `dreamina user_credit`
**查结果：** `dreamina query_result --submit_id=<id>`

## 生成后检查

封面图生成后，逐项检查：

- [ ] 四宫格布局是否规整（2x2 等分）
- [ ] 白色分割线是否清晰（2px）
- [ ] 三行文字是否完整（无缺笔、无乱码、无残字）
- [ ] 文字是否水平垂直居中、无倾斜/扭曲
- [ ] 颜色是否与选中的配色方案一致
- [ ] 第二行描边和发光是否清晰可见，文字是否压得住背景
- [ ] 整体缩略图可读性（缩小到手机屏幕尺寸仍能辨认文字）

任一检查项不通过 → 调整提示词重新生成，最多重试 2 次。
